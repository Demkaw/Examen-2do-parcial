Alice's Arsenal Registry & Characters
--Descripción
Aplicación web que muestra un registro en el cual se pueden crear, buscar/filtrar (mediante un algoritmo con ciclo while), actualizar/editar y eliminar objetos de una colección de armas del universo de Alice: Madness Returns y personajes originales hechos por mi, integrados bajo la perspectiva de Alice Liddell y su dominio mental.

-Funcionalidades implementadas
Colección de artefactos de combate (Cuchillo Vorpal, Molinillo de Pimienta, etc.) y personajes propios (Goliatt, el títere de peluche que le gusta té; Daria, la repostera que le gsutan hacer postres exóticos; y Lilith, la estudiante que le gusta tocar el piano).

-Efectos visuales y estilos personalizados con CSS centralizado (style.css), utilizando tipografía Times New Roman y detalles en rojo carmesí

-GUI de temática "gótica" y oscura, sencilla y ttratando de que sea fácil de entender

Interactividad en el navegador con soporte del LocalStorage 

--Requisitos
Un navegador web moderno (basado en Chromium, Firefox, Safari o Edge).

Acceso a los archivos locales del repositorio o despliegue en GitHub Pages.

--Instrucciones de uso
Ejecución local
-Se descarga o clona el repositorio manteniendo la estructura de carpetas (css/, js/, images/).
-Abre el archivo index.html con tu navegador.

Navega y utiliza los elementos interactivos disponibles en el sitio (inspeccionar expedientes de armas y personajes propios, forjar nuevos registros, buscar en tiempo real, editar, eliminar y respaldar en el almacenamiento local).
